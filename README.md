# Personal Mini-Toolkit

A robust, menu-driven Python application that brings together core programming concepts—including variables, input/output, loops, conditionals, dynamic lists, and imported modules.

## What This Toolkit Does
1. **To-Do List Manager**: Lets you dynamically view, add, and remove tasks from an interactive list while the program runs.
2. **Number Guessing Game**: Challenges you to guess a randomly generated secret number with real-time higher/lower feedback.
3. **Tip & Bill Splitter**: Calculates totals, tips, and splits restaurant bills evenly among any group size.

## How to Run It
Make sure you have Python installed, then run the main script from your terminal:
```bash
python toolkit.py# plp-python-week8
